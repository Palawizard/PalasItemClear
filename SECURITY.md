# Security Policy

## Supported versions

Security fixes target the latest published release across every supported Minecraft band and loader listed in [docs/SUPPORT.md](docs/SUPPORT.md).

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository. Do not open a public issue containing exploit details or sensitive server information.

Include the affected artifact (Minecraft band and loader), reproduction steps, expected impact, and any suggested mitigation. You can expect an initial response within seven days.
